            Amigos

            Importar mensagens do Discord

            1. Abra discord.com/developers/applications, clique em New Application e vá em Bot.
            2. Ligue Message Content Intent e clique em Reset Token para copiar o token.
            3. Em OAuth2 → URL Generator, marque bot e as permissões View Channels e Read Message History. Abra o link gerado e adicione o bot ao seu servidor.
            4. Cole o token aqui. Ele fica só na memória enquanto importa: não é salvo nem vai para ninguém além do Discord.
